# 数独 · 境 / Sudoku Atelier

一款适合手机竖屏的数独游戏，包含 100 个逐步进阶的唯一解关卡、毛玻璃界面与本地 AI 解题助手。

**[开始游玩 / Play](https://yjj0339.github.io/sudoku-atelier/)**

## 游戏特色

- 100 关、10 章节。前十关只有 8–17 个空格，末段包含高难度推演题。
- 全部题目经过唯一解校验，并按本地求解器的技巧与搜索成本排序。
- 手机分层菜单、双排大数字键、逐层返回和下拉收起。
- 三种配色、三种玻璃材质、日夜模式、可读性与动效选项。
- AI 分析候选分布、定位线索、填写一格或整盘、逐步演示解题。
- 无限提示、笔记、自动候选数、撤销、重做、连续填写。
- 每日挑战、星级、成就、自动存档、存档导出与导入。

AI 使用浏览器内的逻辑与搜索算法，不需要账户或 API 密钥。使用 AI 作答会标注辅助成绩。AI 演示使用棋盘副本，不覆盖玩家进度。

## 游玩与存档

手机或电脑浏览器均可直接打开上方网址。首次加载需要联网；资源缓存完成后，同一浏览器支持离线访问。进度保存在当前浏览器的本地存储中，不会上传到服务器。

本地版和公开网站使用不同存档。需要转移时，先在原版本的「我的 → 偏好设置 → 存档与数据」导出，再在新版本导入。新浏览器、清理浏览器数据或更换设备前，请保留备份。

## 本地开发

本项目是纯静态 HTML、CSS 和 JavaScript，没有外部脚本、字体或图片依赖。使用任意静态 HTTP 服务器提供当前目录，即可游玩。`standalone.html` 是可直接打开的单文件离线版。

主要文件：

- `index.html`：页面入口。
- `app.js`：游戏状态、分层界面、存档与交互。
- `engine.js`：约束求解、逻辑讲解、候选数与题目生成。
- `levels.js`：固定的 100 关题库。
- `style.css`、`experience.css`：响应式布局、玻璃材质与动效。
- `sw.js`、`manifest.webmanifest`：离线缓存与 Web App 元数据。

难度指标描述当前算法的求解成本，不代表通用的人类难度认证。所有关卡都有唯一解。
